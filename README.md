# Homebrew tap for Tabla

[Tabla](https://github.com/naylinndev/tabla) is a free, open-source database client
for PostgreSQL, MySQL, SQL Server, Oracle, ClickHouse, SQLite, DuckDB, MongoDB and Redis.

```bash
brew tap naylinndev/tabla
brew install --cask tabla
```

Update with `brew upgrade --cask tabla` (or **Install and restart** inside Tabla).

`Casks/tabla.rb` is written by Tabla's release workflow each time a release is
published; don't edit it by hand.
